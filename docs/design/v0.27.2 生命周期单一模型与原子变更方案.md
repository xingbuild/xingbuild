# v0.27.2 生命周期单一模型与原子变更方案

父版本：v0.27.1 / `cbf832d48ea2483c911f3cd494486a627caf7068`
来源：v0.27.1 产品/架构验收阻断
contentImpact：compatible；不改变页面、内容事实或线上身份。

## 必须收口

- `V272-01`：只保留现有 `site-snapshot-v1` 作为 snapshot 真源；移除或改为适配器的未接入 `site-snapshot-v2` helper，不得存在第二套 snapshot 身份算法。
- `V272-02`：ContentSet Candidate 与 immutable ChangeSet 原子提交；任一写入失败都清理本次临时文件，不留下半成品，active 不变。
- `V272-03`：revision 的 `sourceHash` 必须来自 canonical source 字节/规范化值，不能从 `sourceProof` 引用文本推导；valueHash 继续来自规范化内容值。
- `V272-04`：无 target 变化时复用现有 ContentSet/ChangeSet 身份，不生成新的 ContentSet、snapshot 或发布输入。
- `V272-05`：真实 SitePublication durable record 只保留明确引用与必要 manifest；不重复嵌入完整 verification/runtime 对象，并由 readback 硬断言。

## 不变边界

- 不改页面 IA、组件、视觉、schema、正文、审核、media、active ContentSet 或线上状态。
- 不新增 CMS、第二发布器、数据库或事件系统；复用现有生命周期模型与唯一 Coordinator。
- 不物理删除、不迁移、不 content publish、不 product transport。

## 验收

1. 同一真实 ContentSet prepare：变化 target 只有一个 revision/ref，未变化 entry 原 identity/hash；无变化输入返回现有身份。
2. 模拟 Candidate/ChangeSet 任一写入失败，active、candidate、ChangeSet 均无半成品。
3. sourceHash 与 canonical source 内容核对一致，proof 变化不改变 sourceHash。
4. 真实 SitePublication assembly/readback 只含允许字段；禁止完整 snapshot/runtime/verification 嵌套对象。
5. 真实旧 ContentSet、内容检查、release gates 通过；exact tag/build/preflight 完整。
