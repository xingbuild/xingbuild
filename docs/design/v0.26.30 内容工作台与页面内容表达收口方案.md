# v0.26.30 内容工作台与页面内容表达收口方案

状态：正式方案
父版本：`v0.26.29` / `691ffd68f6f18c037ab816b91de8867cae4c624e`
contentImpact：`compatible`

## 目标

Xing 可以在本地工作台编辑所有需要维护的页面文字，立即看到受影响页面的结果；内容结构保持稳定，空内容自动消失；确认后按既有产品与内容发布边界上线。

## 功能项与完成标准

| 编号 | 功能项 | 完成标准 |
| --- | --- | --- |
| `P30-01` | 页面内容 target 覆盖 | `/`、`/products`、`/business-observations`、`/observations`、`/about` 的可编辑可见字段均登记 source/field/route/consumer；未登记字段硬失败 |
| `P30-02` | 统一长文模型 | About 与经营观察共同使用 `long-form-document-v1`；正文支持段落、列表、回车换段；标题、摘要、目录、图形为可选投影，不复制第二套编辑器 |
| `P30-03` | 可选结构收紧 | 说明、摘要、Why、figure、architecture、resume 缺失时不渲染、不留占位，父级间距自动收紧；有内容时保持既有视觉 token |
| `P30-04` | 首页内容节奏 | B 端产品展示与最新观察简讯由首页父级管理间距；复用既有 Web/Mobile rhythm；空/非空两态均无零间距或页面私有 token |
| `P30-05` | 简历入口 | 只显示“查看简历”“下载简历”；两者使用同一受保护 PDF；下载名为 `金星简历YYYYMMDDHHmm.pdf`；不显示 HTML/PDF/内部文件名 |

## 架构边界

- canonical ignored content 是唯一可编辑源；target registry 是唯一字段与消费者映射。
- 修改一个 target 只刷新其 `consumerViews`；不触发无关页面、全站 reload、全站 build、ProductArtifact 或 ContentSet。
- About 与经营观察只共享长文 schema；页面投影、可见结构和生命周期仍独立。
- 旧 string、`content-rich-text-list-v1`、`responsive-text-slot-v1` 由 adapter 兼容读取；不要求一次性重写既有内容。
- 内容事实、review、media、active ContentSet、SitePublication、Coordinator 和线上状态不由本版本直接修改。

## 最小交接规则

候选和正式方案只使用功能编号与完成标准。跨 task 交接只传：

```text
处理项：P30-xx
目标：...
完成标准：...
禁止：...
```

不在交接中重复职责名称、负责人或多套状态。职责由 task registry 确定；Task 标题标记只服务 Xing 管理。完成依据是代码、测试和证据，不是口头状态。

## 验收

1. 五路由所有登记 target 均能从工作台定位、编辑和局部预览。
2. About/经营观察用同一长文 schema，正文换行和列表保留，稳定 ID 不变。
3. 可选内容的有/无两态均无错误空白、无无关 route/frame 更新。
4. 首页节奏在 Web/Mobile 通过，空简讯状态自动收紧。
5. 简历字节、受保护源 hash、查看/下载链接和动态文件名通过。
6. active/review/recovery/release/SitePublication/ProductArtifact 前后不变；产品 transport 与 `elon ops` 内容发布仍分开。
7. 只有实际页面视觉或可访问性变化才进入 `elon ui` 验收。

## 不纳入本版本

- `DL-01～DL-04` 内容数据生命周期：继续保留在 `XBUILD-CONTENT-DATA-LIFECYCLE-001`。
- `CL-01～CL-05` 历史派生物清理：继续保留在 `XBUILD-HISTORICAL-DERIVED-ARTIFACT-CLEANUP-001`。
- 不删除历史证据，不迁移存储，不创建第二个发布引擎或 deployment。
