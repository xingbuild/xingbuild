# v0.26.25 工作台固定选择区与独立预览滚动方案

状态：正式产品方案

父版本：`v0.26.24` / `4d26a16fc332c3399d9fe5fb15130235a9d44633`

## 1. Xing 的使用目标

工作台反复使用时，页面入口和内容入口必须始终可见。Xing 不应在 Web/Mobile 预览的长页面中上下移动后，再回到页面选择或重新寻找内容字段。

## 2. 工作台布局

```text
页面下拉选择（固定）
内容字段横向选择（固定，可左右拉动）
────────────────────────────────
左：自然文本编辑       右：Web / Mobile 真实页面预览（独立上下滚动）
```

- 页面分类仍由既有 target registry/page definitions 推导，不增加第二套清单。
- 页面选择使用原生 `select`，保证键盘、触摸和窄屏可用。
- 当前页面的字段卡显示在横向滚动条中；字段卡保持语义名称、targetId、可编辑/只读和影响范围。
- 下方工作区保留 v0.26.24 的左侧编辑、右侧真实 Web1280/Mobile390 frame、高亮和关系线。
- 右侧预览区拥有独立 `overflow-y: auto`，预览长内容上下移动时，顶部页面选择和字段选择保持可见。
- 字段选择条拥有独立 `overflow-x: auto`；字段较多时不压缩、不换成难以识别的图标。

## 3. 交互合同

1. 选择页面下拉后，只更新下方字段选择条，不触发页面全量重载。
2. 左右滑动字段条只改变可见字段，不改变当前内容源或预览状态。
3. 选择字段后，左侧编辑器、右侧受影响 Web/Mobile frame、高亮和关系线同步更新。
4. 预览区滚动只影响预览区；页面下拉、字段条和编辑入口仍可用。
5. Web/Mobile 换行、CAS、invalid/恢复、精确 consumer refresh、媒体只读和未审核/未发布状态保持 v0.26.24 合同。

## 4. 边界

- 只改 dev-only content-preview workbench 的布局与交互。
- 不改网站页面 IA、内容 schema、ContentSet、active/review/recovery/release、ProductArtifact、SitePublication、deployment 或 EdgeOne。
- 不把工作台滚动状态写入内容源，不增加 CMS、数据库或第二套 renderer。

## 5. 验收

- 固定 4317 可见页面下拉、横向字段条和独立预览滚动区。
- 五类页面可通过下拉进入；B端产品字段条可左右滚动并选择 intro/Why/模块字段。
- 预览区上下滚动后，页面选择与字段条仍在视口内。
- 选中字段仍能显示四个 Products intro consumer frame 的高亮/关系线。
- `npm run check`、定向工作台测试、固定 4317 实际交互、`release:prepare`、`release:closeout-check`、exact `release:build`、`release:preflight` 和 `git diff --check` 通过。
