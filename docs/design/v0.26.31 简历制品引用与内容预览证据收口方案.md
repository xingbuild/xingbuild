## 架构边界

- career PDF 是受保护源；xingbuild 只读取、校验、复制为不可变发布资产，不修改源文件。
- 内容保存 `ResumeArtifactRef`；artifact registry 保存来源证明与已验证资产；页面组件只消费 resolver 结果。
- 简历内容/引用可独立进入 ContentSet；产品代码、页面 IA、组件和内容发布身份保持分离。
- 预览继续按 target 的 `consumerViews` 局部更新，不触发无关 route、全站 build、ProductArtifact 或 SitePublication。
- DL/CL 生命周期与清理候选不进入本版本。

## 验收

1. About 的查看、下载链接使用同一 PDF，字节和 hash 与 career 源一致。
2. 代码、公开页面和工作台不出现 Kami、HTML、内部文件名或旧 hash。
3. 缺失、未验证或 hash 不一致的 artifact 不渲染入口且无空白占位。
4. 目标级预览编辑、恢复和零写入闭环通过；evidence 的 HEAD/tag 与当前版本完全一致。
5. `R31-07` 通过后才允许 product transport；内容发布仍由 `elon ops` 独立执行。
