# v0.27.8 版本无关生命周期 evidence 门禁方案

## 定位

v0.27.7 build 暴露 release gate 仍硬编码 `v0.27.5` evidence。修复为按当前版本解析，避免新版本读取或改写历史 evidence。

## 必须实现

- `V278-01`：lifecycle evidence 入口、校验器和输出路径按当前 `version` 参数解析；禁止 gate 硬编码历史版本路径。
- `V278-02`：release-build、release-closeout-check、release-preflight 统一读取当前版本 evidence；缺失、身份不匹配或阶段错误硬失败。
- `V278-03`：历史 v0.27.5 evidence 仅只读兼容；新版本不得改写、覆盖或把历史 evidence 当当前版本证据。
- `V278-04`：保留 v0.27.7 NUL-safe committed path、scope classifier、ProductArtifact、ContentSet、SitePublication 和 Content/Ops 边界。

## 验收 checklist

- `C278-01`：v0.27.8 所有 gate 只读取 v0.27.8 evidence，不出现历史版本路径。
- `C278-02`：v0.27.5/v0.27.7 历史 evidence 可只读验证且字节/hash 不变。
- `C278-03`：当前版本 evidence 的 version/baseHead/committedHead/ProductArtifact identity 精确匹配。
- `C278-04`：缺失、错误版本、旧 evidence 冒充当前、post-commit 阶段错误均硬失败。
- `C278-05`：exact release:build 与 release:preflight 在当前版本通过，不产生 tracked dirty。
- `C278-06`：scope classifier 路径回归、ContentSet、SitePublication、.content-workspace 与旧 tag 不变。

## 交付门禁

Engineering 先按 checklist 自 QA 并回传未提交证据；`elon` 复核后回传 `READY_FOR_COMMIT`。此前不得 commit/tag/build/preflight/transport/content publish。
