# v0.26.32 任务注册表治理记录版本方案

## 目标

将 v0.26.31 之后已完成的 `docs/rules/task-registry.md` host 身份更新纳入正式项目版本，恢复版本文件、HEAD、tag 与 ProductArtifact 的一致性。

## 范围

- 保留任务注册表当前事实；按 record-only 纳入本版本。
- 更新 `VERSION.md`、`package.json`、`package-lock.json`、`docs/iterations/current.md` 与 `docs/iterations/history/v0.26.32.md`。
- 重新生成与 v0.26.32 exact HEAD/tag 绑定的 ProductArtifact，并通过 release preflight。

## 不做

- 不修改 UI、IA、schema、组件、视觉 token 或发布器架构。
- 不修改 ContentSet、正文、审核、媒体、active/recovery/release/SitePublication。
- 不运行 content publish；不新增内容事实。
- 不重复 elon ui 视觉验收；本版本无视觉变化。

## 验收

- `npm run check`、`npm run release:prepare`、`npm run release:closeout-check` 通过。
- annotated `v0.26.32` 精确指向 HEAD，工作区 clean。
- `release:build` 与 `release:preflight` 通过，三份 dist manifest 精确绑定 v0.26.32/HEAD。
- 变更范围仅为任务注册表治理记录与版本记录；产品/内容运行事实不变。
