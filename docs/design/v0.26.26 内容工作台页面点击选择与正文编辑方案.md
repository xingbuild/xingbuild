# v0.26.26 内容工作台页面点击选择与正文编辑方案

状态：正式产品方案

父版本：`v0.26.25` / `aee49a3a4a6801fc43d82374a37ad99703c35dc9`

## 1. Xing 的真实使用目标

Xing 不应该先理解 targetId、fieldPath 或一排技术字段卡，才能修改内容。操作路径必须是：

```text
选择页面 → 在右侧真实页面点击文字 → 左侧编辑 → 右侧立即看到变化
```

工作台不是 CMS，也不是新的内容源；它是 canonical ignored content 的安全编辑与预览入口。

## 2. 页面结构

```text
本地编辑预览工具
选择页面（固定下拉）
────────────────────────────────────────
左：当前被点击内容的编辑器（独立上下滚动） | 右：当前页面 Web / Mobile（主要空间、独立滚动）
```

- 顶部只显示标题与原生页面下拉。
- 移除可见状态卡、当前字段 targetId、影响路由 JSON、横向字段选择条。
- 右侧页面内的内容文字显示轻量可点击边界；当前选中项显示强调边界与关系线。
- 左侧只显示语义字段名、简短影响页面说明、Web/Mobile 编辑框和保存状态；不显示技术身份。
- 左侧编辑器有自己的 `overflow-y`；右侧预览保持 `sticky` 并有自己的滚动容器。左侧滚动不改变右侧页面的位置或滚动状态。
- 窄屏退化为自然上下布局，不制造双栏横溢出。

## 3. 内容 target 范围

同一 `content/registry/content-targets.json` 继续是唯一白名单。进入工作台的文字 target 包括：

| 页面 | 可编辑内容 |
| --- | --- |
| 首页 | 定位标题、说明、共享空状态文字 |
| B 端产品 | 产品标题、intro、Why、module 说明、closing 文案、按钮标签等 |
| 经营观察 | 文章标题/摘要与文章正文块 |
| 观察文章 | 每个 observation 的标题、摘要、brief、段落、evidence claim、事实边界 |
| 关于我 | 标题、摘要、lead、heading、paragraph、callout、列表项、定义列表 term/description |

以下内容不属于正文编辑：路由、schema、组件、CSS、页面固定 IA 文案、媒体文件与 mediaId、来源/审核/许可字段、产品工程事实。

## 4. 稳定身份与数据边界

- article/profile rich-document block 与 list/definition item 使用稳定 `id`；只增加身份元数据，不改现有可见文字。
- observation 的多段 `paragraphs` 通过 `content-rich-text-list-v1` 作为一个结构化正文槽编辑；编辑框中的换行对应原数组段落，保存仍写回数组，不把 JSON 暴露给 Xing。
- 目标的 `sourcePath`、`fieldPath`、`projectionRoutes`、`valueType` 仍由 registry 读取；未知、未登记、非文本或不安全路径硬失败。
- 预览仅写 `.content-workspace/content/**` 的 canonical ignored source；`active.json`、ContentSet、review、recovery、release、ProductArtifact、SitePublication 和线上状态只读。

## 5. 交互与刷新

1. 页面下拉改变页面分类；对观察文章选择具体已登记 slug 的正文 target，右侧加载该文章详情页。
2. 父页面向当前页面的所有文本 target 请求标记；iframe 内的可见文字元素收到轻量 outline 与 pointer cursor。
3. Xing 点击页面文字后，工作台定位到同一 target，左侧 editor 显示语义名称与影响范围；不显示 targetId。
4. 保存执行 source/value hash CAS 与原子替换；有效更新通过 session SSE 进入 TargetImpact，只刷新受影响 route×viewport。
5. 无效、半写入、恢复和 CAS 冲突保留 last-valid 页面；不得把内容编辑转成 Vite full reload、产品 build 或发布动作。

## 6. 验收

- 五类页面下拉与当前页面 Web/Mobile 真实 frame 可用。
- Products、About、Business Article、Observation detail 至少各有一个正文文字可点击并进入左侧 editor。
- 一次正文有效修改可在受影响 frame 立即看到，未受影响页面/iframe 不刷新。
- rich-document 列表、定义列表、文章段落、observation 段落的结构与换行保持。
- 左侧滚动时右侧稳定；右侧滚动不带动页面下拉和左侧编辑器。
- preview 退出后 lease、PID、profile、temp 清理；active/review/release/SitePublication/ProductArtifact hash 不变。
- 只进行工作台能力定向 QA 与一次工作台体验验收；日常内容修改不重复触发 `elon ui` 全站验收。

## 7. 发布边界

Xing 在本地工作台确认内容后，交给 `elon ops` 走独立内容 prepare/build/review/publish。产品 Engineering transport 不因内容预览或内容编辑自动触发；正文编辑不改产品版本。
