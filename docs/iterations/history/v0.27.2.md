# v0.27.2 — 生命周期单一模型与原子变更

父版本：v0.27.1 / `cbf832d48ea2483c911f3cd494486a627caf7068`

## Engineering 收口

- `site-snapshot-v1` 是唯一 SiteSnapshot 身份源；治理层 helper 仅委托既有 v1 工厂。
- Candidate 与 immutable ChangeSet 通过同一 atomic commit 边界写入；注入失败会清理临时文件和本次新路径，active 指针保持不变。
- ContentRevision sourceHash 读取 canonical source bytes（无文件时使用规范化 source value），不再哈希 sourceProof 引用文本；valueHash 继续来自规范化内容值。
- 无 target 变化时复用 active ContentSet identity，不生成新的 ContentSet、ChangeSet、snapshot 或发布输入。
- SitePublication durable readback 只保留引用/结果摘要和必要 manifest，拒绝完整 verification/runtime 对象。

## 验证边界

- 本版本不修改页面、内容事实、审核、媒体、active ContentSet 或线上状态。
- 本版本不运行 content publish、product transport 或 EdgeOne。
