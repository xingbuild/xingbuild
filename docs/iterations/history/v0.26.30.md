# v0.26.30 内容工作台与页面内容表达收口

父版本：`v0.26.29` / `691ffd68f6f18c037ab816b91de8867cae4c624e`

## 实现

- 登记五路由可见内容 target，并在 target read/authoring 前对未知字段与重复 block/item ID 硬失败；目标影响面继续由 registry 的 consumer routes/views 决定。
- About 与经营观察通过 `long-form-document-v1` 统一读取、编译与反编译；旧字符串与既有 ignored content source 保持兼容，未编辑内容不迁移。
- RichDocument、文章、About、Home、Products、观察简讯和模块输出稳定 target 标记；可选 summary、figure、architecture、Why、resume 缺失时返回空投影，不产生占位 DOM。
- 简历入口收口为同一受保护 PDF 的“查看简历”“下载简历”，下载名按 `金星简历YYYYMMDDHHmm.pdf` 动态生成；首页节奏由既有父级 token 管理。

## 验证与边界

- 通过 `npm run check`、内容/文章/Practice checks、long-form/target/preview/source-Candidate 定向回归和 content-enabled build；release QA 中历史内容 fixture、旧断言与 macOS 浏览器 sandbox 失败按 retained/environment 分层，不作为本版本实现结论。
- 预览只按 target consumerViews 局部刷新；active/review/recovery/release/SitePublication/ProductArtifact 与 DL/CL 治理候选保持只读未变。
- 本版本不执行 product transport、content publish 或 EdgeOne，待产品/架构验收后再决定下一步。
