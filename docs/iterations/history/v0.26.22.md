# v0.26.22 — 内容预览运行时 v2 与局部刷新闭环

父版本：`v0.26.21` / `3bde62d80a1bb666ee5846e30dd10fa631fbf29f`

## 实现

- 新增项目级 Preview Runtime v2 与 session-scoped SSE event broker，工作台按 TargetImpact 精确刷新真实消费者的 Web1280/Mobile390 frame。
- `products.robotaxi.intro` 由注册 projection routes 与 page definitions/contentRefs 共同证明影响 `/`、`/products`；无关 route 不刷新。
- source watcher 支持 debounce、原子保存/半写入 retry、invalid last-valid、outside-selected-target 与恢复状态；不依赖隐式 Vite HMR 或 `path=*` full reload。

## 边界

- 只读取 canonical ignored content、target registry、页面定义与 active ContentSet baseline；不写 active/review/recovery/release/SitePublication/ProductArtifact，不运行 content publish/product transport/EdgeOne。
- 不修改正式网站 UI/IA/视觉、内容正文、审核、媒体事实或发布链路。

## 验证

- `v02620`/`v02621` 兼容回归与 `v02622` runtime 定向测试 15/15 通过。
- 固定 4317 content-enabled 浏览器证据：有效 intro 编辑只刷新四个受影响 frame；invalid 保留 last-valid；outside-selected-target 不刷新；恢复原字节；active/review/recovery/release/SitePublication/ProductArtifact hash 不变；lease 与端口清理。
