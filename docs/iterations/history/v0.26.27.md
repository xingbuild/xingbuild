# v0.26.27 — 内容工作台页面导航即选择与局部预览

## 范围

- 移除 dev-only 工作台顶部页面下拉；右侧真实站点主导航成为唯一页面选择入口。
- 页面导航通过受控 `preview-navigation-click` 在工作台两个 Web/Mobile frame 内同步 route，不离开工作台、不触发全站 reload。
