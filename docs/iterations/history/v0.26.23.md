# v0.26.23 — 全页面自然文本内容编辑工作台

父版本：`v0.26.22` / `6868f0d03a581f1d2a9d6b27e5783b085f958adf`

## 实现

- 新增 `content-authoring-value-v1`：内容作者直接输入自然文本；响应式字段由内部编译器生成 `responsive-text-slot-v1`，Web/Mobile 只保存断点而不复制语义文本。
- 工作台由唯一 `content/registry/content-targets.json` 展开全部页面文本 target，覆盖 `/`、`/products`、`/business-observations`、`/observations`、`/about`；媒体字段在同一清单中可见但只读。
- 新增本地 authoring GET/POST API、source/value hash CAS、原子替换和 session-scoped SSE；只刷新目标的真实 consumer route×viewport。
- 修正 shared empty-state target 指向 canonical `content/home.json`，并修复动态 observation target 展开路径。

## 边界

- 只写 `.content-workspace/content/**` 的当前 target 源文件；不写 `src/`、active ContentSet、review/recovery/release、ProductArtifact、SitePublication、deployment 或 EdgeOne。
- 不改变页面 IA、布局、组件、视觉 token、媒体审核和发布链路；内容确认后仍由 `elon ops` 独立发布。

## 验证

- authoring compiler、target inventory、consumer impact 定向测试通过。
- 固定 4317 真实闭环：编辑 `products.robotaxi.title` → SSE `valid-updated`、revision 递增、仅 `/products` Web/Mobile consumer views 刷新；原始 JSON 字节已恢复，preview lease/端口已清理。
